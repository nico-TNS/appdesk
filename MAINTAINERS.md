# Maintainers and release roles

| Role | Proposed responsible person | State |
| --- | --- | --- |
| Repository owner and author | [@nico-TNS](https://github.com/nico-TNS) | Account confirmed; public publication authorized |
| Reviewer | @nico-TNS | Reviews external contributions; no independent reviewer claimed |
| Release and signing approver | @nico-TNS | Configure after SignPath admission |

Before requesting production signing, confirm MFA, repository ownership, approval rights and recovery contacts. Do not invent additional maintainers to meet an application criterion. If a second reviewer joins, document the role and require review for security-sensitive changes.
