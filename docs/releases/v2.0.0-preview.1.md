# AppDesk 2.0.0 — première préversion non signée

Première publication publique du projet AppDesk, sous licence MIT, pour préparer sa candidature à SignPath Foundation.

## Contenu

- Un fichier Windows x64 : `MonInstallateur.exe`, avec le catalogue et le moteur embarqués.
- Interface WPF, sélection des applications, progression globale et état par application.
- Neuf entrées de catalogue et six éditions Office au choix.
- Compilation et vérifications depuis les sources par GitHub Actions.
- Somme SHA-256 fournie dans `SHA256SUMS.txt`.

## Statut de cette préversion

**Le binaire n’est pas signé. Aucune signature ni approbation SignPath n’a été obtenue.** Windows Smart App Control ou une politique d’entreprise peut bloquer son exécution. Le projet ne demande pas de désactiver ces protections.

Les vérifications couvrent les sources, la compilation, les plans silencieux, le rendu de l’interface et les simulations de file. Les installations réelles et la revue de sécurité du moteur restent à effectuer avant une release de production.

## Prérequis et limites

- Windows 10/11 x64, .NET Framework 4.8 et WinGet.
- Connexion Internet et autorisation Windows pour démarrer la file d’installation.
- FortiClient VPN nécessite son MSI/EXE **complet et officiel**. Le petit lanceur en ligne est refusé pour le mode silencieux.
- Office nécessite une licence correspondante ; aucune activation de contournement n’est fournie.
- Les profils VPN et comptes 3CX restent à configurer séparément.
- Le moteur PowerShell embarqué et la compatibilité avec les politiques de sécurité doivent être revus avant signature de production ; une signature sur l’EXE ne signe pas automatiquement le script extrait.

Les installateurs des éditeurs ne sont pas inclus dans la release. Voir le README, `SECURITY.md`, `PRIVACY.md` et les instructions de désinstallation.
