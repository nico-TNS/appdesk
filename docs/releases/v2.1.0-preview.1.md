AppDesk 2.1 adds automatic publisher-source resolution and an integrated installation report.

- Refresh the WinGet catalogue before resolving the seven WinGet applications.
- Retrieve the current Office Deployment Tool from Microsoft's Download Center rather than a pinned URL or old local setup. Office uses the latest build of the selected product/channel.
- Automatically download the highest full VPN-only x64 version published by the official Fortinet regional portal; verify Fortinet's signature and embedded version before execution. A manual package override remains available. The regional release may differ from the global channel; see [source policy](https://github.com/nico-TNS/appdesk/blob/main/docs/SOURCES.md).
- Enable updates of selected existing applications by default. Existing Office editions are not removed and FortiClient is not automatically downgraded.
- Automatically display an integrated final report with per-application results, error details, exit codes, unprocessed items, reboot status, text export and access to logs.

**Unsigned preview. SignPath admission and production signing remain pending.** Automated source tests, queue simulation, resource smoke testing and compilation are checks, not proof of successful end-to-end installation of every application. An existing different Office edition is deliberately preserved and reported as an error.

Only AppDesk's executable and its checksum are attached. Third-party installers are downloaded at runtime, not redistributed in this release.
