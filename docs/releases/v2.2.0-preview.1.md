AppDesk 2.2 adds a dedicated **Désinstaller Office…** action.

- Detect compatible installed Office Click-to-Run suites and list them in a separate confirmation with No selected by default.
- Download the current official Microsoft Office Deployment Tool and verify Microsoft's signature.
- Remove only the confirmed suite product IDs using `<Remove All="FALSE">`. Standalone OneNote, Visio and Project are not targeted. Do not automatically remove MSI/Store installations.
- Refuse removal while Office applications are running. No forced application closure, forced reboot or automatic reinstall.
- Show progress and a final report with an explicit uninstallation result.
- Test confirmation requirements, product scope, mixed-queue rejection, simulation and report rendering without removing installed applications.

**Unsigned preview.** Real removal has not been performed on the development PC. The new button prepares removal but no application is removed without a separate user confirmation and Windows UAC authorization. Existing automatic download and installation features remain available.
