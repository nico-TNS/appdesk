AppDesk 2.3 strengthens transfer, queue and diagnostic reliability.

- Download into temporary files; bounded retries for transient failures; preserve existing files and clean up partial transfers on failure.
- Prevent simultaneous installation queues from new AppDesk engines.
- Capture worker stdout/stderr and display engine-startup failures in the final report.
- Keep Office installation and update channels aligned, including LTSC 2024.
- Improve reboot-required handling and explain Windows Installer busy results.
- Add fault-injection tests for interrupted transfers, retry limits, invalid hosts, concurrent queues, worker failures and report rendering.

Recorded real outcomes on the development PC include successful Microsoft 365 suite removal, standalone OneNote removal and Office LTSC 2024 Standard x64 installation. These do not establish compatibility with every Windows/Office configuration. See [the compatibility matrix](https://github.com/nico-TNS/appdesk/blob/main/docs/COMPATIBILITY.md).

**Unsigned preview.** FortiClient installation/connection, the other Office editions, clean-machine Windows 10 testing, production signing and runtime security review still require validation. No new catalogue application was installed or removed by the fault tests.
