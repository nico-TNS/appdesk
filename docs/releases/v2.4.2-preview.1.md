# AppDesk 2.4.2 — contrôle FortiClient avant téléchargement

Le moteur comparait les versions FortiClient après avoir téléchargé le package complet. Il pouvait ainsi transférer environ 208 Mio alors que la version installée était déjà identique ou plus récente.

Le contrôle a été déplacé avant le téléchargement. AppDesk consulte toujours les métadonnées du portail officiel régional, puis :

- version installée identique ou supérieure : application conservée, aucun package téléchargé ;
- version installée inférieure : téléchargement et installation de la mise à jour ;
- version installée inconnue : erreur explicite avant tout transfert de package ;
- mises à jour désactivées et application présente : aucun téléchargement.

Les contrôles de signature, de version et de provenance restent appliqués aux packages nécessaires. La sélection d'un package manuel conserve son fonctionnement précédent.

Le cas remonté sur le poste TNS affichait FortiClient installé **7.4.3.4726** et disponible **7.4.3.6002** : ce téléchargement correspond à une mise à jour justifiée. Le correctif évite les téléchargements dans les cas où FortiClient est déjà à jour.

Tests de non-régression exécutant la fonction de production avec entrées simulées : version identique, version installée plus récente, version plus ancienne, comparaison numérique 9/10, version inconnue, application absente et conservation sans mise à jour. Aucun logiciel du poste n'a été installé ou supprimé par ces tests. La CI exécute aussi les vérifications existantes.

Préversion non signée. Office 2021 et les fonctions de la version 2.4.1 restent disponibles. Les versions affichées pendant une file correspondent à la dernière recherche ; l'inventaire est actualisé automatiquement à la fin de la file.
